# Calculadora MVC - PD3

Este repositorio contiene la implementación de una calculadora básica desarrollada en Java. El proyecto está construido bajo el patrón de arquitectura **Modelo-Vista-Controlador (MVC)** e implementa el **Patrón Strategy** para garantizar un código escalable y libre de sobreingeniería.

## ✨ Características Principales
* **Arquitectura Limpia:** Separación total entre la interfaz gráfica (Vista) y la lógica matemática (Modelo).
* **Escalabilidad:** Gracias al patrón Strategy, se pueden agregar nuevas operaciones matemáticas en el futuro sin modificar los archivos base.
* **Bajo Acoplamiento:** El Controlador y el Modelo son independientes de las operaciones específicas.
